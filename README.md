# OpenCS

**OpenCS** — open-source десктопное приложение для расчёта и проверки строительных конструкций по российским нормативным документам (СП, ГОСТ).

Реализован полный цикл: от ввода геометрии сечения, задания материалов и нагрузок до расчёта прочности, трещиностойкости, огнестойкости, кручения и теплопередачи. Включает собственный МКЭ-решатель для рам и оболочек с интеграцией расчёта сечений, backend внешнего OpenSees для нелинейных задач и генератор расчётно-пояснительных отчётов.

## Возможности

### Железобетонные стержневые сечения (СП 63.13330)

- **Фибровый метод** — деление сечения на волокна (прямоугольная сетка, триангуляция Рупперта, метод продвижения фронта)
- **Контурный метод** — интегрирование по теореме Грина для полигональных областей без фибр
- Расчёт прочности (I группа предельных состояний): поиск предельного коэффициента нагружения, проверка по предельным деформациям сжатого бетона (ε_b2, ε_b0) и растянутой арматуры (ε_s,ult)
- Расчёт трещиностойкости (II группа предельных состояний): момент образования трещин и ширина раскрытия (acrc)
- Диаграммы «момент — кривизна», в том числе косой изгиб и полная кривизна с учётом жёсткости на участках с трещинами
- Наклонные сечения и поперечная арматура: проверки по поперечной силе и моменту в наклонном сечении, замкнутые хомуты, отклик сечения на сдвиг
- Предварительное напряжение: потери по СП 63 и учёт ε_p во всех видах расчёта
- Двухстадийные сечения для сборно-монолитных конструкций и усиления

### Железобетонные плитные/оболочечные сечения (СП 63.13330)

- Кинематика Кирхгофа — Лява (6 компонент: мембранные + изгибные)
- Слоистая модель с послойным интегрированием бетона и арматурных слоёв
- Прочность (ULS): деформационный критерий п. 8.1.30, Wood-Armer, Caprani-Capurso, полная слоистая модель
- Трещиностойкость (SLS): расчёт ширины раскрытия трещин по п. 8.2.15–8.2.18
- Непродолжительное и продолжительное раскрытие

### Стальные сечения (СП 16.13330.2017)

- Проверки прочности (раздел 8): центральное сжатие/растяжение, изгиб, сжатие с изгибом, растяжение с изгибом, поперечный изгиб (срез), кручение, изгиб с кручением, продольный изгиб, местное смятие стенки
- Проверки устойчивости: местная устойчивость стенки и полки
- Конструктивные проверки
- Классификация сечений по п. 7.3
- Автоматическое вычисление геометрических характеристик (A, I, W)

### Комбинации нагрузок (СП 20.13330)

- Основное и особое сочетания
- Типы нагрузок: постоянная (G), длительная (L), кратковременная (Q), особая (A)
- Автоматический разбор имён наборов, пользовательские γ_f
- Огибающая (Envelope) и список комбинаций (Cases)
- Для стержней: [N, Mx, My, Vx, Vy, T]
- Для пластин: [Nx, Ny, Nxy, Mx, My, Mxy, Qx, Qy]

### Расчёт кручения (Сен-Венан)

- Два метода: метод граничных элементов (МГЭ, порт TORSCON) и метод конечных элементов (МКЭ, функция Прандтля)
- Результаты: постоянная кручения It, координаты центра кручения, поле касательных напряжений, максимальное напряжение
- Поддержка линейных (Tri3) и квадратичных (Tri6) конечных элементов

### Теплопередача

- Нестационарная и стационарная теплопередача (уравнение теплопроводности)
- Тепловые граничные условия: конвекция, заданная температура
- Поддержка произвольных тепловых материалов
- Квадратичные тепловые элементы, итерационный решатель Пикара

### Огнестойкость (СП 468, ГОСТ 30247.0)

- Огневые кривые: ISO 834, Hydrocarbon (EN 1991-1-2), Slow Heat
- R-проверки предела огнестойкости по несущей способности и поиск собственного предела огнестойкости
- Фибровый метод: поэлементная γ-редукция с температурным полем
- MVP-метод (максимальных значений параметров)
- Температурная редукция бетона (силикатный/карбонатный/лёгкий заполнитель) и арматуры по СП 468
- Температурная кривизна сечения по профилю температуры

### Собственный МКЭ (CSfea)

- Линейный и нелинейный (метод Ньютона, коротационная формулировка) статический анализ рам (2D/3D) и оболочек
- Элементы: балка Эйлера — Бернулли, оболочки MITC3-подобная T3 и MITC4 (Дворкин — Бате)
- Интеграция с расчётом сечений через адаптер `CSfea.CScore`
- Разреженные матрицы (собственная библиотека + обёртка CSparse)

### Backend OpenSees

- Запуск внешнего `OpenSees.exe` через генерируемые Tcl-модели с полным артефакт-манифестом (входы, stdout/stderr, код возврата, provenance)
- Секционные задачи: анализ «момент — кривизна», пространственная диаграмма взаимодействия N–Mx–My
- Нелинейные оболочечно-стержневые модели: нативные материалы бетона и арматуры, слоистые оболочки, геометрическая нелинейность, стадийное нагружение, послойный отклик и нормативный аудит по СП 63
- Граничные условия и связи: `fix`, `equalDOF`, `rigidLink`, диагностика конфликтующих степеней свободы

### Плоские конструктивные элементы и сетка Gmsh

- `PlanarRegion` — плита/стена/произвольная пространственная пластина с локальным базисом, контуром и отверстиями; авторинг прямо из 3D-вида расчётной схемы
- Пространственные зоны армирования (`PlateRebarField`/`RebarZone`) с автогенерацией плитных сечений, штриховкой и прямым DXF-импортом геометрии и зон
- Построение расчётной сетки внешним `gmsh.exe` (mixed T3/Q4, physical groups, provenance, инвалидация снимка) и адаптеры снимка сетки к обоим backend-ам
- Геометрически привязанные нагрузки, внутренние constraint-объекты и связи между регионами
- Производственные фрагменты: вертикальная стена, узел примыкания перекрытия, многоэтажная колонна
- Стержневая аналогия полосы плиты: редукция плитного отклика в эквивалентное стержневое сечение, перенос нагрузок и восстановление нагрузки производной балки

### Отчёты

- Нейтральный документ отчёта с рендерингом в HTML, Markdown, DOCX (OpenXML, без внешнего конвертера) и PDF (печать через WebView2)
- Собственные SVG-иллюстрации сечения и диаграмм материалов с растеризацией для форматов без SVG
- Реестр поставщиков отчётов по видам расчётных задач: `strain_state`, `limit_force`/`limit_moment`/`limit_axial`, `cracking`, `crack_width`, `total_curvature`

### Импорт/экспорт

- DXF (netDxf) и AutoCAD COM API — импорт геометрии сечений и контуров плит
- ЛираСАПР — импорт схем и усилий (ЗН/РСН/РСУ) из CSV/текстовых выгрузок и через COM API
- SCAD — импорт текстовых схем, наборов РСУ2 и усилий из .xls
- CSV — экспорт результатов
- Excel — импорт .xls (ExcelDataReader)
- SQLite — персистентность всех данных проекта

## Структура решения

```
OpenCS.sln
├── CSmath/                   Чистая математика (векторы, матрицы, сплайны, геометрия)
├── CSTriangulation/          Триангуляция (Advancing Front, Ruppert CDT)
├── CScore/                   Доменная модель и расчётный движок (fibre/контурный методы)
│   ├── CrossSection.cs       Стержневое сечение
│   ├── PlateSection.cs       Плитное сечение
│   ├── MaterialArea.cs       Фибровое разбиение и интегрирование
│   ├── Sp63/                 Расчёты по СП 63.13330
│   ├── Sp63Shear/            Наклонные сечения и поперечная арматура
│   ├── PrestressLoss/        Потери предварительного напряжения
│   ├── Steel/                Стальные сечения (СП 16)
│   ├── Combinations/         Комбинации нагрузок (СП 20)
│   ├── Fem/                  Доменная модель расчётных схем
│   ├── Import/               Импортёры ЛираСАПР и SCAD
│   ├── Planar/               Плоские конструктивные элементы и фрагменты
│   ├── PlateRebar/           Пространственные зоны армирования
│   └── PlateStrip/           Стержневая аналогия полосы плиты
├── CScore.Fire/              Огнестойкость (СП 468, надстройка над CScore)
├── CScore.Tests/             Тесты доменного слоя и расчётного движка
├── CSfea.Sparse/             Разреженные матрицы
├── CSfea.Sparse.CSparse/     Обёртка CSparse (interop)
├── CSfea.Core/               МКЭ-ядро (балки, оболочки, коротационная формулировка, решатели)
├── CSfea.CScore/             Мост CScore ↔ CSfea (адаптация единиц, осей)
├── CSfea.Thermal/            Теплопередача (МКЭ)
├── CSfea.Torsion/            Расчёт кручения (МГЭ/МКЭ)
├── CSfea.Tests/              Тесты МКЭ/кручения/теплопередачи
├── OpenCS.OpenSees/          Backend внешнего OpenSees (модель, Tcl, запуск, аудит)
├── OpenCS.OpenSees.CScore/   Мост CScore ↔ OpenSees (сечения, материалы, оболочки)
├── OpenCS.OpenSees.Tests/    Тесты backend-а, включая прогоны настоящего OpenSees.exe
├── OpenCS.Gmsh/              Генерация .geo, запуск gmsh.exe, разбор MSH, снимки сетки
├── OpenCS.Gmsh.Tests/        Тесты сеткогенерации, включая прогоны настоящего gmsh.exe
├── OpenCS.Reporting/         Документатор отчётов (HTML/Markdown/DOCX/PDF, SVG)
├── OpenCS.Reporting.Tests/   Тесты рендереров и экспорта отчётов
├── OpenCS/                   WPF-приложение (точка входа)
│   ├── ViewModels/           ViewModel'и
│   ├── Views/                WPF-контролы и кастомная отрисовка
│   ├── Tasks/                Расчётные задачи и их обработчики
│   ├── Services/             Сервисы (файлы, диалоги, логи, отчёты)
│   ├── Interop/              Interop-сборка ЛираСАПР (AutoCAD подключается поздним связыванием)
│   ├── Converters/           Конвертеры привязок
│   └── Utilites/             DatabaseService, настройки, утилиты
└── OpenCS.Tests/             Тесты приложения и интеграционные сценарии
```

Каталоги `TriTest/` и `StrainTest/` — отладочные песочницы (триангуляция, примеры расчёта деформаций); в `OpenCS.sln` они не включены и собираются отдельно при необходимости.

## Сборка и запуск

Требования: [.NET 9.0 SDK](https://dotnet.microsoft.com/download/dotnet/9.0).

```bash
dotnet build OpenCS.sln
dotnet run --project OpenCS
```

Сборка под Windows (WPF). Проекты без WPF-зависимостей (`CS*`) можно собрать и под другие платформы.

Тесты:

```bash
dotnet test CScore.Tests
dotnet test CSfea.Tests
```

`CScore.Tests`, `CSfea.Tests` и `OpenCS.Reporting.Tests` не требуют внешних программ.
Часть тестов в `OpenCS.Gmsh.Tests` и `OpenCS.OpenSees.Tests` запускает настоящие `gmsh.exe` и
`OpenSees.exe` и без них падает: путь к Gmsh зашит в тестах как
`C:\Tools\gmsh-4.15.2-Windows64\gmsh.exe`, путь к OpenSees берётся из `OPENSEES_EXE`
(по умолчанию `C:\Tools\OpenSees\bin\OpenSees.exe`). Тесты экспорта отчётов, требующие
WebView2, пропускаются, если среда недоступна.

## Системные требования

- ОС: Windows 10/11
- .NET 9.0 Runtime
- Для импорта DXF: не требуется дополнительного ПО
- Для импорта из AutoCAD или ЛираСАПР через COM API: установленное соответствующее ПО
- Для нелинейных расчётов через OpenSees: внешний `OpenSees.exe` (путь задаётся переменной `OPENSEES_EXE`, параметром задачи или берётся из `C:\Tools\OpenSees\bin\OpenSees.exe`)
- Для построения расчётной сетки плоских элементов: внешний `gmsh.exe` (путь задаётся в настройках приложения)
- Для экспорта отчётов в PDF: WebView2 Runtime (входит в состав актуальных Windows 10/11)

## Назначение

OpenCS предназначен для инженеров-проектировщиков, научных сотрудников и студентов строительных специальностей. Программа позволяет выполнять поверочные расчёты существующих и проектируемых конструкций в соответствии с актуальными российскими нормами.
